## 用职场讲AI基础概念

有一个实力硬到能砍穿地球，但是没有工作经验的万能实习生小A（AI），它开始上班了，你是它的领导，开始给它派活（prompt），你在它的桌面（context window）上放了一堆资料（context），让它看完后给你汇报结果。

小A记得你喜欢简洁的汇报（memory），而且你也要求它稳重一些/活泼一些（temperature），它根据这个风格进行汇报，但是你发现它的汇报有些地方在胡扯（Hallucination），翻资料看了一下果然如此（Verification），你留了个心眼不再百分百相信小A说的话，防止被坑。

为了让它不这么胡扯，你让实习生先查看相关资料，让它根据资料而不是记忆来汇报（RAG），并且给它设定SOP，固定它的工作流程，减少出错（Workflow）。随着工作越来越复杂，这些实习生不止于汇报，加强后变得像助理（Agent），它会帮你干一些拆任务跑代码的活，干完后再汇报。

但有时候小A干活也会变慢，它表示牛马一下干太多的活，它暂时顶不住了，新的需求待会再提（Rate Limit），同时它这一整个月的精力有限（Quota），压榨完了就得等下个月恢复，或者你可以选择奖金激励它继续干。

为了保护公司的机密资料，你决定让小A直接在公司内部办公，不再把资料发到外部，但是你需要把电脑和环境给实习生准备好（local model）。有时候，小A也要和其他部门合作，按照约定好的格式填表对接资源，不需要亲自跑去部门掰扯合作形式（API），资源调动需要合作权限卡（API key），合作部门只认卡不认人，费用按照消耗了多少工作量来计算（token），所以你留了第二个心眼，权限卡千万别泄露，否则别人可以花你的预算、用你的服务。

小A上大学时，不断学习，练习，纠错，慢慢形成自己的判断能力（Training），然后牛马开始正式干活，把大学学到的知识拿出来解决问题（Inference）。像小A这样的实习生有很多，有的读过很多资料，会写、会总结（LLM），有些实习生会更贵，它们不仅会读文档，还会看图片、听声音、分析表格、生成图片（Multimodal）。

## 括号术语速查

说明：以下是按官方文档、标准文件和行业通用定义整理的中文转述；部分新兴术语暂无唯一标准定义。

✅ AI：人工智能，使系统能够为给定目标生成预测、内容、建议或决策等输出的技术领域。

✅ Prompt：提示词或输入指令，用来引导模型生成符合要求的输出。

✅ Context Window：上下文窗口，模型在一次请求中能够处理的最大输入与输出信息范围，通常按 token 计量。

✅ Context：上下文，当前请求中提供给模型并可被模型用于生成输出的信息。

✅ Memory：记忆，产品或系统在当前请求之外保存并可再次使用的信息，不是模型参数天然保存的完整聊天记录。

✅ Temperature：温度参数，用于调节模型采样随机性；数值越高，输出越随机，数值越低，输出越稳定。

✅ Hallucination：幻觉，模型生成不受事实或给定来源支持、但看起来像事实的错误或误导性内容。

✅ Verification：验证，对输出结果进行事实核查、来源核查、测试或人工复核的过程。

✅ RAG：检索增强生成，通过先检索外部资料，再把检索结果提供给生成模型来辅助回答的方法。

✅ Workflow：工作流，由一组预定义步骤、条件或任务组成的执行流程。

✅ Agent：智能体，能够感知输入、规划或选择行动，并通过工具或环境交互完成目标的系统。

✅ Rate Limit：速率限制，服务在指定时间窗口内允许的最大请求频率或请求数量。

✅ Quota：配额，账号、服务或资源在一定周期内允许使用的总量。

✅ Local Model：本地模型，部署并运行在本地设备或自有服务器上的模型，而不是完全依赖远程托管服务。

✅ API：应用程序编程接口，软件系统之间按约定互相访问功能或交换数据的接口。

✅ API Key：API 密钥，用于标识、认证或授权 API 调用方的凭证。

✅ Token：模型处理文本的基本单位，可能是字符、词或词的一部分。

✅ Training：训练，使用数据调整模型参数，使模型学习输入与输出之间规律的过程。

✅ Inference：推理，使用训练完成的模型根据输入计算并生成输出的过程。

✅ LLM：大语言模型，使用大规模文本数据训练、用于理解和生成自然语言的大型模型。

✅ Multimodal：多模态，指系统或模型能够处理或生成文本、图像、音频、视频等多种类型的信息。
